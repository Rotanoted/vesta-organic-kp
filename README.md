# КП — VESTA ORGANIC

Одностраничное коммерческое предложение на редизайн и перенос vestaorganic.ru на MODX.
Next.js 15 (App Router), без внешних зависимостей — только `next`, `react`, `react-dom`.

## Локально

```bash
npm install
npm run dev      # http://localhost:3000
```

## Деплой на Vercel

**Вариант 1 — через CLI (быстрее всего):**

```bash
npm i -g vercel
cd kp
vercel            # первый раз: логин + подтверждение настроек
vercel --prod     # боевой деплой
```

Vercel сам определит Next.js, ничего настраивать не нужно.

**Вариант 2 — через репозиторий:**

1. Запушить папку `kp` в отдельный репозиторий на GitHub.
2. На vercel.com → Add New → Project → импортировать репозиторий.
3. Framework Preset определится как Next.js автоматически, Root Directory — `kp`, если пушили весь проект целиком.

## Что править

Весь текст — в [app/page.js](app/page.js), оформление — в [app/globals.css](app/globals.css).
Цены и сроки лежат в таблице внутри секции «Варианты и стоимость».

Ставка в расчётах — 1500 ₽/ч. Если меняете ставку, пересчитайте четыре строки таблицы:
50–70 ч, 170–210 ч, 250–290 ч, 300–360 ч.

## Основание

Цифры в КП взяты из отчётов в `../reports/`:

- `00-summary.md` — сводка, находки, вопросы клиенту
- `01-content.md` — инвентаризация контента и медиа
- `02-plugins.md` — плагины, конструктор, формы, редиректы
- `03-theme.md` — тема, шаблоны, фронтенд
- `04-issues.md` — состояние сайта, сверка с аудитом Лабрики, нестандартный функционал
- `05-estimate.md` — декомпозиция часов и варианты объёма
